# KURO Educational Game

A mobile-friendly browser quiz game by **JAPETH A. MIRAS**.

## Publish with GitHub Pages
Open **Settings → Pages → Deploy from a branch**, choose **main** and **/(root)**, then Save.

When deployment finishes, visit:
https://japethmiras96-eng.github.io/kuro-educational-game/

## Features
- 150 levels: 50 Easy, 50 Average, 50 Difficult
- 10 questions per level; timed questions and difficulty-based points
- Pass a level with at least 6 correct answers
- Levels unlock in sequence; progress is saved in the browser on each device
- Responsive for mobile phones, tablets, and computers
- Developer credit: JAPETH A. MIRAS

## Content note
This first release uses a starter question bank. Questions repeat across levels in shuffled order; it does not yet contain 1,500 unique questions. Please review content before classroom use.

KURO is a browser game, not a native Android APK or Google Play Store app.
